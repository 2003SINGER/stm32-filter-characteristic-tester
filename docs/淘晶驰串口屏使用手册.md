# 滤波器测试仪 - 显示屏使用手册

本手册详细说明了基于 **淘晶驰 (USART HMI)** 2.4寸串口屏的 UI 设计架构、通信协议及操作逻辑。

## 1. 硬件规格与连接
* **型号：** 淘晶驰 T0 系列 (2.4寸)
* **分辨率：** $320 \times 240$ 像素
* **通信方式：** 异步串口 (UART)
* **引脚连接：**
    * `VCC` -> $5\text{V}$
    * `GND` -> `GND`
    * `TX`  -> STM32 `PA10` (RX)
    * `RX`  -> STM32 `PA9` (TX)
* **波特率：** $115200\text{ bps}$ (需确保单片机与屏幕配置一致)

---

## 2. UI 架构设计
为了保证数据在切换视图时不丢失，本设计采用了 **单页架构 (SPA)**。所有控件均放置在 `page0`，通过 `vis`（可见性）指令实现页面切换。

### 2.1 视图分类
1.  **图形视图 (Graph View)：** 核心显示波形控件 `s0`。
2.  **数据视图 (Data View)：** 显示详细的测量指标文本 `t1`~`t8`。

### 2.2 核心控件清单
| 控件ID | 类型          | 功能描述                       | 作用域   |
| :----- | :------------ | :----------------------------- | :------- |
| `s0`   | 波形 (Wave)   | 显示幅频（黄）与相频（绿）曲线 | 局部     |
| `t2`   | 文本 (Text)   | 当前系统工作状态指示           | **全局** |
| `t5`   | 文本 (Text)   | 品质因数 (Q) 显示              | **全局** |
| `t6`   | 文本 (Text)   | 特征频率 ($f_0$) 显示          | **全局** |
| `t8`   | 文本 (Text)   | 滤波器类型诊断结论             | **全局** |
| `b2`   | 按钮 (Button) | 开始/停止测量控制开关          | 局部     |

---

## 3. 数学映射逻辑 (Bode 图)
波形控件 `s0` 的尺寸为 $205 \times 181$ 像素。单片机发送的像素值 $Y$ 必须映射到 $0 \sim 180$。

### 3.1 幅频特性 (Gain)
* **范围：** $-40\text{ dB} \sim +20\text{ dB}$ (总跨度 $60\text{ dB}$)
* **映射公式：** $$Y_{pixel} = (Gain_{dB} + 40) \times 3$$

### 3.2 相频特性 (Phase)
* **范围：** $-180^\circ \sim 0^\circ$ (总跨度 $180^\circ$)
* **映射公式：** $$Y_{pixel} = Phase_{deg} + 180$$

### 3.3 频率坐标 (X轴)
横轴为对数坐标，跨度为 $10\text{ Hz} \sim 100\text{ kHz}$。单片机需在 $205$ 步扫频中完成全量打点。

---

## 4. 通信协议 (指令集)

### 4.1 屏幕接收指令 (STM32 -> HMI)
所有指令必须以 `0xFF 0xFF 0xFF` 结束。

* **更新文本：** `t5.txt="1.41"`
* **画波形点：** `add 1,0,120` (ID为1的控件，通道0，高度120)
* **清空波形：** `cle 14,0`
* **隐藏/显示：** `vis s0,0` (隐藏波形)

### 4.2 屏幕发送指令 (HMI -> STM32)
按钮 `b2` 触发时，屏幕通过串口发送单字节十六进制数：
* **`0x01`：** 用户点击“开始测量”。
* **`0x00`：** 用户点击“停止测量”（中断当前扫频）。

---

## 5. 操作流程
1.  **上电：** 屏幕显示“待机中...”，默认进入图形视图。
2.  **开始：** 点击 `b2` 按钮，屏幕向单片机请求开始，按钮文字变为“停止测量”。
3.  **观察：** * 点击 **【分析图像】**：实时观察波特图动态生成。
    * 点击 **【综合数据】**：查看计算出的 Q 值、频率等具体数值。
4.  **完成：** 测量结束后，按钮自动复位，状态更新为“测试完成”。



## 示例代码
```
#include "hmi_driver.h"
#include <math.h>

int main(void) {
    HAL_Init();
    SystemClock_Config();
    MX_USART1_UART_Init(); // 确保波特率设为了 115200
    
    // 1. 开启屏幕监听
    HMI_Init();
    
    // 状态记录变量，防止重复刷新UI
    uint8_t last_measure_state = 0;
    
    while (1) {
        
        // 检测到屏幕要求开始测量，且刚刚是从待机切换过来的
        if (hmi_is_measuring == 1 && last_measure_state == 0) {
            last_measure_state = 1;
            
            // 告诉屏幕：我收到指令了，你把按钮变成"停止"，清空波形
            HMI_SetMeasureState(1); 
            
            // 开始对数扫频，正好 205 个点填满横轴
            for (int i = 0; i < 205; i++) {
                
                // 💥 核心防线：每次循环查一下，有没有被点击“停止”中断
                if (hmi_is_measuring == 0) {
                    break; // 被打断了，直接跳出 for 循环！
                }
                
                // --- 这里替换成你的真实测量代码 ---
                // float current_hz = 10.0 * pow(10, (i * 4.0 / 204.0));
                // 设置DDS频率(current_hz)...
                // 读取ADC并计算 gain 和 phase...
                
                // 模拟数据：生成一个假的谐振波形
                float sim_gain = -40.0f + 60.0f * exp(-pow((i-100), 2)/1000.0f);
                float sim_phase = -180.0f + i * (180.0f / 205.0f);
                
                // 动态更新波形 (直接丢入物理浮点数，库会自动转成像素)
                HMI_AddWavePoint(sim_gain, sim_phase);
                
                HAL_Delay(5); // 稍微延时，给DAC和ADC响应时间
            }
            
            // 扫频结束逻辑：判断是正常扫完，还是中途被打断
            if (hmi_is_measuring == 1) {
                // 正常扫完，展示分析结果
                HMI_UpdateFinalData(1.41f, 1050.0f, "巴特沃斯 (Butterworth)");
                
                hmi_is_measuring = 0; // 单片机自动切回待机状态
                HMI_UpdateText("b2", "开始测量"); // 按钮复位
            } else {
                // 中途被打断，通知屏幕进入中止状态
                HMI_SetMeasureState(0);
            }
            
            last_measure_state = 0; // 重置状态记录
        }
    }
}
```
